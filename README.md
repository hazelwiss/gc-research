This is a collection of my own research, documentation, test roms and benchmarking roms. Feel free to copy or use however you wish. Or contribute :)

Various tests, benchmarks and research is made using [libogc2](https://github.com/extremscorner/libogc2), so thanks to them for their amazing library!

# Building

In order to build this properly, run the following commands
```
make setup
make package
```

This will generate a `package.tar.gz` that will include every test.
